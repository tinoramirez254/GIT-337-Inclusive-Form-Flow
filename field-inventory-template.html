F2 · Task and Data Plan

This inventory documents the information needed for a custom baseball card label request, including field requirements, constraints, and privacy considerations.

Visible label / question Why necessary now? Required? Native control/type Submitted name/value Autocomplete/inputmode Constraint/instruction Sensitivity and minimization decision
Collector name Identifies who is requesting the label. Yes text collector_name name Enter first and last name. Names only for this demonstration.
Email address Provides a way to contact the collector. Yes email email email Must use a valid email format. Use email addresses. No phone number collected.
Player name Identifies the player featured on the card. Yes text player_name N/A Enter the player's name. Public baseball information only.
Card year Identifies the card's release year. Yes number card_year N/A Enter a year from 1900 to 2026. Non-sensitive card information.
Card manufacturer Identifies the company that produced the card. Yes select manufacturer N/A Select Topps, Bowman, Panini, or Other. Non-sensitive card information.
Card set Identifies the specific baseball card product. Yes text card_set N/A Example: Topps Chrome. Non-sensitive card information.
Card parallel Identifies special card variations. No text parallel N/A Example: Gold Refractor. Optional because not every card has a parallel.
Card serial number Documents numbered cards. No text serial_number N/A Example: 05/50. Optional because many cards are not numbered.
Label background style Determines the visual appearance of the label. Yes radio group background_style N/A Choose one background style. Design preference only.
Label finish Determines the requested label finish. Yes select label_finish N/A Select matte, glossy, or holographic. Design preference only.
Additional instructions Allows collectors to describe special design requests. No textarea instructions N/A Maximum 300 characters. Optional; users should not provide personal information.
Design acknowledgment Confirms the collector understands this is a demo. Yes checkbox acknowledgment N/A Must be checked before submitting. No additional personal data collected.
